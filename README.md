Whether you're a designer, artist, or just someone with a vivid imagination, Dream Canvas is here to help you create beautiful images from simple text prompts.

## 🌟 About The Project

Dream Canvas is a user-friendly application built with modern web technologies. The core of this project lies in its ability to interpret natural language and generate corresponding images. This project was developed to explore the fascinating intersection of natural language processing and computer vision, making AI-powered image generation accessible to everyone.

### ✨ Features:

* **Text-to-Image Generation:** Simply type in a description, and the AI will generate a unique image for you.
* **User-Friendly Interface:** A clean and intuitive UI built with React for a smooth user experience.
* **Fast & Efficient:** Optimized to deliver high-quality images in a short amount of time.
* **Creative Freedom:** Experiment with different prompts to explore a wide range of artistic styles.
* **Model Selection:** Choose from different AI models for varied artistic outputs.
* **Image Count & Aspect Ratio:** Control the number of images generated and their dimensions.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

Make sure you have Node.js and npm installed on your machine.

* npm
    ```sh
    npm install npm@latest -g
    ```

### Installation

1.  **Clone the repo**
    ```sh
    git clone [https://github.com/king-4-u/Dream-Canvas-Text-to-Image-Generator.git](https://github.com/king-4-u/Dream-Canvas-Text-to-Image-Generator.git)
    ```
2.  **Install NPM packages**
    ```sh
    cd Dream-Canvas-Text-to-Image-Generator
    npm install
    ```
3.  **Enter your API Key**
    Create a `.env` file in the root directory of the project and add your OpenAI API key:
    ```
    OPENAI_API_KEY = 'YOUR_API_KEY'
    ```
4.  **Run the application**
    ```sh
    npm start
    ```

---

## 💡 Usage

Once the application is running, open your browser and navigate to `http://localhost:3000`.

1.  Enter a descriptive text prompt in the input field (e.g., "A futuristic city at sunset with flying cars").
2.  Select your preferred **Model**, **Image Count**, and **Aspect Ratio**.
3.  Click on the "Generate" button.
4.  Wait for a few moments, and your generated image(s) will appear on the screen!
